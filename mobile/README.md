# Мобильное приложение (Flutter)

Одно приложение для iOS и Android с режимами учащегося и инструктора. Запуск — см. [README в корне](../README.md#мобильное-приложение).
## Структура

```
mobile/
├── pubspec.yaml                   зависимости
├── analysis_options.yaml          правила анализатора кода
├── l10n.yaml                      настройки локализации
├── assets/images/                 изображения
├── lib/
│   ├── main.dart                  точка входа
│   ├── app.dart                   тема, локализация, навигация
│   ├── core/
│   │   ├── api/
│   │   │   ├── api_client.dart        запросы к /api/v1
│   │   │   └── api_error.dart         разбор ответа с ошибкой (код, сообщение, поля)
│   │   ├── storage/
│   │   │   ├── token_storage.dart     токены в Keychain / Android Keystore (ТЗ 3.2.3.6)
│   │   │   └── offline_cache.dart     расписание и прогресс без сети (ТЗ 3.2.2.4)
│   │   ├── theme/app_theme.dart       палитра и контраст (ЛР 3, п. 5.3)
│   │   └── widgets/                   состояния загрузки и ошибки сети
│   ├── features/
│   │   ├── auth/                      вход, смена временного пароля, согласие на обработку ПД
│   │   ├── instructors/               сценарий «Выбрать инструктора» — экраны 1–4 прототипа
│   │   ├── schedule/                  календарь, свободное время, запись и отмена
│   │   ├── progress/                  прогресс обучения
│   │   └── instructor_mode/           режим инструктора: своё время, отметка занятий
│   └── l10n/app_ru.arb            тексты интерфейса (белорусский — файлом app_be.arb)
└── test/                          тесты виджетов
```
